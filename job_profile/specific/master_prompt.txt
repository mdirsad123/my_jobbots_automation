CRITICAL MARKDOWN PARSING RULE:
The current parser recognizes a line that starts with `**` and ends with `**` and contains `|` as the centered blue subtitle. Therefore:
- Do NOT write Education entries as `**B.Sc... | ... | **` with bold markers at both ends.
- Do NOT write the entire Target Roles line inside `**...**` when it contains `|`.
- Use partial bolding instead, for example:
  `**B.Sc. Information Technology** — University of Mumbai | ... | 9.13 CGPA`
  `**Target Roles:** Data Engineer | Python Developer | ...`
This keeps Education and Target Roles left-aligned.
